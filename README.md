## Tujuan Project

Membuat website statis yang menampilkan informasi lengkap tentang gym, mulai dari pengenalan, program yang ditawarkan, hingga cara menghubungi. Project ini juga bertujuan menerapkan workflow kolaborasi menggunakan Git & GitHub (branch, Pull Request, dan code review).

## Fitur / Section Website

- **Hero Section** — Nama gym, tagline, dan call-to-action
- **About** — Sejarah singkat, visi & misi, serta keunggulan
- **Programs** — Daftar program membership, fasilitas, dan trainer
- **Contact** — Form kontak dan informasi kontak
- **Footer** — Copyright dan media sosial
- Navigasi smooth scroll antar section
- Tampilan responsif (bisa dibuka di HP)
